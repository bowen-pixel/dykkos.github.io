# dykkos.github.io

Personal website: https://dykkos.github.io/

Plain HTML with browser-default styling. No build step or dependencies, except MathJax for blog equations.

Preview with `python3 -m http.server 8000`.

- `math.html`: mathematics PDFs and MAT1307 Boolean Circuits (notes in progress)
- `cs.html`: neural network and Web3 side projects
- `ai-safety.html`: TAISI fellowship and Trajectory Labs

The original pages, PDF URLs, and homepage image are preserved.
