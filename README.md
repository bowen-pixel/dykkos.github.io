# Bowen's personal website

Static personal site published with GitHub Pages at https://dykkos.github.io/.

## Preview

From this directory, run `python3 -m http.server 8000` and open http://localhost:8000.
No dependencies or build step are required. Blog equations use MathJax from jsDelivr.

## Content

- `index.html`: homepage and current interests
- `math.html`: mathematics PDFs and MAT1307 Boolean Circuits (notes in progress)
- `cs.html`: WikiClick, Solidity payment channels, BNB support toolkit
- `ai-safety.html`: TAISI fellowship and Trajectory Labs
- `blog.html`: study journal
- `intro.html`: about
- `misc.html`: personal extras, retaining the original homepage image
- `style.css`: shared responsive styling

Existing PDF URLs and page URLs are preserved. When MAT1307 notes are ready, add the file under `pdf/` and replace the in-progress message with a link.
